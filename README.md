# helenedraux.com

Personal website for [Hélène Draux](https://helenedraux.com) — methods for knowledge and evaluation.

Built with [VitePress](https://vitepress.dev). Content is organised around AI analytics, evaluation, writing, and builds.

## Development

```bash
npm install
npm run docs:dev      # local preview
npm run docs:build    # production build
npm run docs:preview  # preview the build
```

Published to GitHub Pages on push to `main`.
