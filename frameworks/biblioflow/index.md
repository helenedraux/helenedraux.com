# BiblioFlow

BiblioFlow is a framework for structured bibliometric analysis in defined institutional or domain contexts. It applies method-level decomposition to citation and publication data, organising analysis into explicit stages rather than producing aggregate indicators in a single pass.

Documentation for this framework is forthcoming. What will be published here: the analytical context BiblioFlow is designed for, how it relates to the methods on this site, and a partial worked example. Full implementation detail will not be public.
