# DimQuery

DimQuery is a framework for dimensional querying of research outputs — structuring analytical questions so that each dimension of interest is explicit, inspectable, and separately evaluable.

Documentation for this framework is forthcoming. What will be published here: the problem DimQuery addresses, its relationship to multi-dimensional evaluation methods, and a partial example. Full implementation detail will not be public.
